# home-energy-calculator

Energy Usage Calculator

## Purpose
This tool estimates household energy consumption and recommends battery storage sizes for New Zealand homes. It models base load, spa pools, EV charging, and pool equipment to help plan backup power capacity.

## Usage
1. Open `index.html` in a modern web browser.
2. Adjust the input values for your home.
3. Press **Calculate Battery Requirements** to see daily usage and recommended battery capacity.

## Assumptions
- Designed for NZ 230V/60A electrical supply (≈13.8kW maximum).
- Uses typical appliance efficiencies and operating patterns.

## Disclaimer
Estimates are for guidance only. Consult a qualified professional to confirm actual requirements before purchasing equipment.
